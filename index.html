✅ ဝင်ထားသည်:
Gemini API Key လိုပါတယ် — Google AI Studio မှာ အခမဲ့ ရယူပြီး ဒီနေရာမှာ ထည့်ပါ။

Gemini အခမဲ့ Key တစ်ခုလျှင် (Project တစ်ခုလျှင်) တစ်နေ့ ၁၀–၁၅ ကြိမ်ခန့်သာ ရသည် — Key များ ထည့်ထားလျှင် quota ပိုရပြီး၊ တစ်ခု 429 (quota ပြည့်) ဖြစ်လျှင် နောက် Key သို့ အလိုအလျောက် ပြောင်း သုံးမည်။ Key အားလုံးကို ဤ Browser ၏ localStorage ထဲတွင်သာ သိမ်းသည်။

ဘာသာပြန် ကိရိယာ သုံးရန် Groq API Key လိုပါတယ် — console.groq.com မှာ အခမဲ့ ရယူပြီး ဒီနေရာမှာ ထည့်ပါ။

✦ AI မျက်နှာဖုံး

Prompt ထည့်ရန် လိုပါတယ် — ဘယ်လို ပုံ လိုချင်သလဲ ရေးပါ (သို့) ခေါင်းစဉ် အရင် ထည့်ပါ။

🆓 Free နည်းလမ်းမှာ Key မလိုပါ။ Gemini နည်းလမ်းမှာတော့ ပုံ (image) quota ရှိသော ကိုယ်ပိုင် Key လိုပါတယ် — Gemini အခမဲ့ Key များတွင် ပုံ quota 0 ဖြစ်နေတတ်သည်။

🎙️ အသံ ထုတ်မယ်

0 လုံး · စာရှည်လျှင် အပိုင်း ခွဲ၍ ထုတ်ပေးမည်
စာသား ထည့်ရန် လိုပါတယ် — ပြောစေချင်သော စာသား အရင် ရေးပါ။

Edge အသံ = အခမဲ့ — နေ့စဉ် quota မရှိ။ သုံးရန် Login ဝင်ထားရန် လိုသည် (Settings ထိပ်ဆုံး အကောင့် အပိုင်း)။ အသံကို chip အတိုင်း သတ်မှတ်ပြီး ဖြစ်သည်။

Gemini: ကိုယ်ပိုင် Key ဖြင့် Google သို့ တိုက်ရိုက် ချိတ်ဆက်သည်။ အခမဲ့ အဆင့်မှာ Key တစ်ခုလျှင် တစ်နေ့ ၁၀–၁၅ ကြိမ်ခန့်သာ ရသည် — Key များ ထည့်ထားလျှင် 429 ဖြစ်တိုင်း နောက် Key သို့ အလိုအလျောက် ပြောင်းမည်။ Edge: အခမဲ့၊ quota မရှိ၊ Login လိုသည်။

အသံ ရွေးမယ်

📉 ဖိုင် ချုံ့မယ်

Telegram bot ဆီ ပို့ရန် အသံဖိုင်ကို 20 MB အောက် ချုံ့ပေးသည် (bot က 20 MB ထက် ကြီးသော ဖိုင် ဒေါင်းလုဒ် မလုပ်နိုင်ပါ)။ အသံကို စကားပြော အတွက် လုံလောက်သော အဆင့် (mono · 24 kHz) ဖြင့် ထိန်းထားသည်။
